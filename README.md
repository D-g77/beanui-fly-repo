# BeanUI.fly
A modern soft‑body vehicle physics engine built from a fork of Rigs of Rods.

BeanUI.fly is an experimental evolution of the classic node‑beam physics system,
aiming to modernize rendering, deformation, and simulation quality while keeping
the open‑source spirit alive.

## ✨ Features (current + planned)
- Upgraded node‑beam physics (higher resolution, more constraints)
- Early flexbody-style mesh deformation
- Modernized UI layer (the “BeanUI” system)
- Improved material behaviour (stress, bending, break thresholds)
- Experimental renderer upgrades
- Cleaner modding structure for vehicles and maps

## 🚀 Goals
- Create a BeamNG‑style soft‑body simulator using open‑source foundations
- Modernize Rigs of Rods without losing compatibility
- Provide a flexible physics sandbox for experiments and modding

## 🧪 Status
Actively in development. Expect bugs.
